# Брзочитач — Алат за учење читања на ћирилици

**Брзочитач** је једноставна веб апликација заснована на технологији брзог приказивања речи (RSVP), креирана са посебном наменом: **да помогне деци која тек савладавају читање на ћирилици.**

Уместо да дете буде преплављено целим страницама текста што често изазива отпор, овај алат приказује речи једну по једну. Овакав приступ омогућава потпуни фокус на тренутну реч, олакшава спајање слогова и смањује фрустрацију код почетника. Овај пројекат представља темељ за дугорочну едукативну вредност, креиран као користан ресурс који ће расти заједно са децом и који им се може оставити као трајна вредност.

## 🌟 Зашто је Брзочитач одличан за децу?

*   **Фокус на једну реч:** Уклања ометања која доносе дугачки текстови. Дете гледа само у центар екрана и не губи се у редовима.
*   **Прилагодљив темпо:** Брзина се може драстично смањити како би пратила ритам детета које тек сриче слова и постепено повећавати како постаје сигурније.
*   **Чиста ћирилица:** Апликација вуче текстове директно са [Брзочитач Blogger-а](https://brzocitac.blogspot.com/) (или из твојих `.txt` фајлова), омогућавајући да се припреме приче, бајке или кратке реченице искључиво на ћирилици.
*   **Визуелно вођење:** Маркер у центру речи (црвено слово) помаже оку да се фиксира на право место, што убрзава препознавање облика речи.

## 🚀 Како се користи?

*   **Читање са блога:** Апликација аутоматски повлачи постове. Идеално је да се на блогу објављују кратке, поучне приче прилагођене узрасту.
*   **Унос сопственог текста:** Увек можеш директно налепити било који ћирилични текст или учитати локални текстуални фајл за вежбу.
*   **Паметне паузе:** Апликација се аутоматски мало дуже задржава на знацима интерпункције, дајући детету времена да схвати крај реченице и удахне.
*   **Читање на слогове:** За апсолутне почетнике, текст се може припремити тако да сваки "размак" представља један слог, па апликација избацује слог по слог.

## 💻 Постављање на GitHub Pages

Овај пројекат је спреман за хостовање на GitHub Pages потпуно бесплатно.

1.  Направи нови репозиторијум на GitHub-у са именом **`brzocitac`**.
2.  Отпреми (push-уј) фајлове `index.html` и `README.md` у тај репозиторијум.
3.  На GitHub-у, уђи у репозиторијум, иди на картицу **Settings**, па у менију са леве стране пронађи **Pages**.
4.  Под опцијом **Source** изабери **Deploy from a branch**.
5.  Изабери `main` (или `master`) грану и кликни **Save**.
6.  Кроз пар минута, апликација ће бити доступна на:
    `https://<tvoje-korisnicko-ime>.github.io/brzocitac/`

## ⌨️ Пречице на тастатури за родитеље и децу

*   **Размак (Space):** Пусти / Паузирај читање (најважније дугме за дете)
*   **Стрелица десно (→):** Скочи једну реч унапред 
*   **Стрелица лево (←):** Врати се једну реч уназад (ако дете треба да понови или пронађе слово)
*   **Стрелица горе (↑):** Повећај брзину читања
*   **Стрелица доле (↓):** Смањи брзину читања
*   **Р (R):** Крени текст испочетка

## 🛠️ Измена извора текстова

Уколико желиш да повежеш апликацију са неким другим блогом на ком ћеш објављивати приче за вежбу, отвори `index.html` и промени URL унутар подешавања:

```javascript
var PODESAVANJA = {
  blog: "https://brzocitac.blogspot.com",
  ...
};
```
