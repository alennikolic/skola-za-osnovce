# Брзочитач (Brzočitač)

Брзочитач је једноставна, брза веб апликација базирана на RSVP (Rapid Serial Visual Presentation) технологији за брзо читање. Апликација је намештена да аутоматски повлачи и учитава текстове директно са [Брзочитач Blogger-а](https://brzocitac.blogspot.com/). Све што објавиш тамо, аутоматски се појављује у овој апликацији.

## 🚀 Могућности

*   **Читање са блога:** Аутоматски привлачи постове преко Blogger RSS/JSONP фида.
*   **RSVP Приказ:** Читање реч по реч (или више њих) са фиксним фокусом, како би се елиминисало померање очију и убрзало читање.
*   **Подешавање брзине:** Подеси WPM (Words Per Minute) у ходу (од 100 до 1200 речи у минути).
*   **Груписање речи:** Читај 1, 2, 3 или 4 речи одједном.
*   **Паметне паузе:** Алгоритам аутоматски прави микро-паузе на знацима интерпункције (тачка, зарез).
*   **Унос текста:** Могућност да налепиш свој текст или учиташ било који локални `.txt` фајл за брзо читање.
*   **Две теме:** Светли и тамни режим приказа.
*   **Памћење напретка:** Апликација локално у прегледачу (Local Storage) памти докле си стигао са којим текстом.

## 💻 Постављање на GitHub Pages

Овај пројекат је спреман за хостовање на GitHub Pages потпуно бесплатно.

1.  Направи нови репозиторијум на GitHub-у са именом **`brzocitac`**.
2.  Отпреми (push-уј) фајлове `index.html` и `README.md` у тај репозиторијум.
3.  На GitHub-у, уђи у репозиторијум, иди на картицу **Settings**, па у менију са леве стране пронађи **Pages**.
4.  Под опцијом **Source** (или Build and deployment) изабери **Deploy from a branch**.
5.  Изабери `main` (или `master`) грану и кликни **Save**.
6.  Кроз пар минута, твоја апликација ће бити доступна на:
    `https://<tvoje-korisnicko-ime>.github.io/brzocitac/`

## ⌨️ Пречице на тастатури

*   **Размак (Space):** Пусти / Паузирај читање
*   **Стрелица десно (→):** Скочи једну реч (или групу) унапред
*   **Стрелица лево (←):** Врати се једну реч уназад
*   **Стрелица горе (↑):** Повећај брзину читања
*   **Стрелица доле (↓):** Смањи брзину читања
*   **Р (R):** Крени текст испочетка

## 🛠️ Измена извора (Блога)

Уколико касније пожелиш да промениш блог са ког се текстови учитавају, отвори `index.html` и пронађи линију у JavaScript коду:

```javascript
var PODESAVANJA = {
  blog: "https://brzocitac.blogspot.com",
  ...
};
```

Овде можеш унети адресу било ког другог Blogger блога.
